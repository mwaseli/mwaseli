## ⚡ Quick Start (5 Minutes)

### Step 1: Run Locally

- Enter: "A beautiful sunset over mountains"
- Click "Generate"
- Wait 15-30 seconds
- Download your image!

### Step 3: Deploy
```bash

# Then follow prompts
```

## 💡 Pro Tips

### For Best Results
- Use detailed prompts (200+ characters)
- Specify style/mood/lighting
- Use aspect ratio for composition
- Be creative with descriptions

### For Faster Generation
- Keep prompts concise (under 500 chars)
- Use simpler styles (HD vs Super Genius)
- Generate lower resolutions first (720p vs 4K)
- Batch similar requests

### For Quality Videos
- Describe motion clearly
- Use keyframe input for better control
- Keep duration under 30 seconds for speed
- Use 720p for good quality + speed balance
