# Free HTML VPS (No Payment Needed)

This repository now includes a simple HTML page with a **free deployment guide** for hosting an application online without entering payment details.

## What this gives you
- A static HTML guide you can open locally.
- A path to deploy for free using:
  - GitHub Pages
  - Netlify (free tier)
  - Cloudflare Pages (free tier)

## Files
- `index.html` – free hosting/VPS-style guide page.

## Quick start
1. Open `index.html` in your browser.
2. Follow the "Deploy for free" section.
3. Pick one provider and publish your app.

## Important note about MetaTrader VPS
MetaTrader (MT4/MT5) needs a running Windows environment for full terminal + EA execution. Truly free 24/7 Windows VPS options are generally not reliable or permanent. If you only need an online dashboard/status page, static hosting from this repo is a free option.
